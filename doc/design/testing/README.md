# Testing

## Test layers

| Layer | Where | What runs | In CI |
|---|---|---|---|
| Unit and integration | `server/test`, `packages/*/test`, `web/src/**/*.test.*` | Everything in-process; SQLite in memory, PostgreSQL and a live sshd only when configured | Yes |
| Interop vectors | `test/interop` | Fixtures generated by TypeScript, decoded independently by Go | Yes |
| Server end-to-end | `server/test/e2e` | crhs in-process, a real `crha` binary, a fake model | Yes |
| Privileged system | `server/test/system/privileged` | One podman container per node with real root, sudo, doas and sshd | Yes |
| WebUI end-to-end | `web/e2e` | A real crhs serving the built WebUI, a real crha node, a fake model | Yes |
| WebUI mock | `web/e2e-mock` | The built WebUI against a mocked API | No |
| Bundled build | `server/test/bundle` | `dist/crhs` copied outside the repository, on SQLite (and PostgreSQL when configured) | Yes |
| Go | `client/**/*_test.go` | Go units | Yes |
| Performance | `server/test/perf`, `web/e2e-mock/perf` | The fake model on real storage; the WebUI under CPU throttling | No |

Details: [Server tests](server.md), [WebUI tests](web.md), [Privileged system tests](privileged.md),
[Interop fixtures](interop.md). The scripts for each suite are in the root and package `package.json`
files; CI is `.github/workflows/ci.yml`. Build the bundle with `pnpm build:crhs`; its smoke test is
`pnpm --filter @crh/server test:bundle`.

## What to run when

| You changed | Run at least |
|---|---|
| Anything | `pnpm check` and `pnpm test` |
| Protocol or Noise | Also the Go tests |
| Storage or migrations | The server tests with `CRH_TEST_PG_URL` set, so both databases run |
| Cluster core, tasks, SSH, agent runtime | Also `pnpm test:e2e` |
| Privilege or the privileged daemon | Also `CRH_TEST_PODMAN=1 pnpm test:system` |
| WebUI | The web unit tests, `pnpm test:ui` and the mock suite |
| Before a release | Everything, both performance suites, and a manual pass on a demo cluster |

`pnpm test` does not include the end-to-end, system, mock or performance suites.

## Prerequisites and environment

Node.js 24.7 or later, pnpm and Go are needed for most suites; the end-to-end suites build `crha`.
Playwright needs Chromium. External services are never started automatically:

| Variable | Enables |
|---|---|
| `CRH_TEST_PG_URL` | The PostgreSQL variants of the server tests; each test database gets its own schema |
| `CRH_TEST_SSH`, `CRH_TEST_SSH_KEY` | The SSH route and SFTP tests against a live sshd |
| `CRH_TEST_SSH_JUMP` | The WebUI SSH wizard test |
| `CRH_TEST_PODMAN=1` | The privileged system tests (rootless podman, Linux) |
| `CRH_CHROMIUM` | A system Chromium for Playwright |
| `PERF_RUNS`, `PERF_STREAM_SCALE` | Repetitions and stream size for the WebUI performance suite |
| `GOCACHE` | A writable Go build cache, when the default is read-only |

Without its variable, a suite is skipped and reported as skipped.

## Known gaps

- The SSH integration tests, the mock and the performance suites are not in CI.
- Go tests run without `-race`.
- Playwright runs Chromium only.

## Conventions

- Name tests after the behavior.
- A conditional skip states its reason. Suites that need an external service check for it and skip
  without it.
- Tests do not depend on the network, the wall clock or the order of other files, and clean up their
  temporary files and processes.
- Interop fixtures are generated, never edited by hand.
- A test that drives a session through the fake model must title the session or queue an extra
  response: a session without a title uses one model response to generate its title after the first
  run.
- Do not assert on log wording unless it is part of a contract.
